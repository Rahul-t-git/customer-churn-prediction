
# Customer Churn Prediction

**Status:** In Progress 🚧

## About the Project
This project uses machine learning to predict whether a customer is likely to leave a service. It uses Python, Scikit-learn, and Streamlit to provide an interactive prediction interface.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Joblib

## Current Features
- Data preprocessing and feature encoding
- Logistic Regression classification
- Class-balanced model for churn prediction
- Churn probability prediction
- Interactive Streamlit web application

## Project Goals
- Compare multiple machine learning algorithms
- Improve model evaluation and understand its limitations
- Deploy the application online

## Run Locally

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Run the application:

```bash
streamlit run app.py
```

## Project Status
This is an educational project under active development. Model evaluation, documentation, and deployment are ongoing.
